# Library Management System

## 1. Название проекта

Library Management System (Система управления библиотекой)

## 2. Тема проекта

Разработка консольного приложения для управления библиотекой с использованием принципов объектно-ориентированного программирования на языке C++.

## 3. Описание проекта

Данный проект представляет собой систему управления библиотекой, которая позволяет работать с различными видами библиотечных материалов. Программа реализована с использованием ООП и демонстрирует применение инкапсуляции, наследования, полиморфизма и абстракции.

Система позволяет добавлять новые материалы, просматривать список объектов библиотеки, брать и возвращать материалы, а также выполнять действия, связанные с чтением или использованием различных типов объектов.

## 4. Базовый класс

Основным базовым классом проекта является абстрактный класс LibraryItem.

LibraryItem представляет общий тип для всех библиотечных материалов и содержит общие характеристики:

- название материала (title);
- год выпуска (year);
- статус доступности (available).

Класс также содержит общие методы для всех объектов библиотеки:

- получение информации об объекте;
- проверка доступности;
- выдача материала;
- возврат материала.

LibraryItem использует виртуальные функции, благодаря чему реализуется полиморфизм.

## 5. Дочерние классы

От базового класса LibraryItem наследуются следующие классы:

Book — представляет обычную книгу. Хранит дополнительную информацию об авторе.

AudioBook — представляет аудиокнигу. Содержит данные об авторе и продолжительности аудиозаписи.

Comic — представляет комикс. Содержит информацию о художнике.

Magazine — представляет журнал. Хранит номер выпуска журнала.

Каждый дочерний класс имеет собственную реализацию методов вывода информации и чтения.

## 6. Интерфейсы

В проекте используются три интерфейса:

IPrintable — отвечает за возможность вывода информации об объекте. Содержит метод printInfo(), который реализуется всеми библиотечными объектами.

IBorrowable — отвечает за управление выдачей и возвратом материалов. Содержит методы:

- borrow() — взять объект;
- returnItem() — вернуть объект;
- isAvailable() — проверить доступность.

IReadable — отвечает за возможность чтения или использования материала. Содержит метод read(), который реализуется в дочерних классах.

## 7. Управляющий класс

За управление библиотекой отвечает класс LibraryManager.

Он выполняет следующие функции:

- хранение списка библиотечных объектов;
- добавление новых материалов;
- вывод всех объектов библиотеки;
- выдача материалов пользователю;
- возврат материалов;
- запуск операции чтения.

LibraryManager работает с объектами через базовый класс LibraryItem*, поэтому может управлять разными типами материалов одновременно.

## 8. Возможности программы

Программа позволяет:

- добавить книгу;
- добавить аудиокнигу;
- добавить комикс;
- добавить журнал;
- посмотреть список всех материалов;
- взять материал из библиотеки;
- вернуть материал обратно;
- прочитать книгу;
- прослушать аудиокнигу;
- работать с разными типами объектов через единый интерфейс.

## 9. Использованные принципы ООП

Инкапсуляция — реализована через закрытые поля классов и методы доступа (getters/setters).

Наследование — используется для создания дочерних классов Book, AudioBook, Comic и Magazine на основе LibraryItem.

Полиморфизм — реализован через виртуальные функции и возможность работать с разными объектами через указатель базового класса.

Абстракция — реализована через абстрактный класс LibraryItem и интерфейсы IPrintable, IBorrowable и IReadable.

## 10. Технологии

Язык программирования: C++

Тип приложения: Console Application

Используемые возможности:

- классы;
- наследование;
- виртуальные функции;
- интерфейсы;
- vector;
- принципы ООП.

## 11. Заключение

Проект демонстрирует создание структурированного приложения на C++ с использованием объектно-ориентированного подхода. Архитектура позволяет легко расширять систему добавлением новых типов библиотечных материалов без изменения существующего кода.
